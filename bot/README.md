# 🎓 بوت تيليجرام البكالوريا المتكامل — نجاحي (Naja7i BAC Bot 🇩🇿)
### *(Clone متكامل ومطور لـ @bacdztopbot يعمل 100% داخل Telegram)*

---

## 📌 نظرة عامة (Overview)
بوت تيليجرام مستقل وشامل مخصص لجميع تلاميذ شهادة البكالوريا في الجزائر (الشعب الست 6).
تم تصميمه وبرمجته باستخدام **grammY** (أسرع وأحدث إطار عمل Node.js لبوتات التيليجرام) ليعمل تفاعلياً بالكامل من خلال الأزرار التفاعلية (Inline Keyboards) والقوائم الدائمة (Reply Keyboards)، بدون الحاجة لفتح المتصفح.

---

## 🌟 الميزات والأقسام الرئيسية

1. 📚 **تصفح الشعب والمكتبة الدراسية:**
   - تغطية شاملة لجميع الشعب الست (علوم تجريبية، رياضيات، تقني رياضي، تسيير واقتصاد، آداب وفلسفة، لغات أجنبية).
   - تصفح مرقم (Pagination) لأكثر من **330 ملف ملخص وسلسلة تمارين** مع أزرار معاينة سريعة وتحميل مباشر من Google Drive.

2. 🏛️ **أرشيف مواضيع وحلول البكالوريا الرسمية (2008 - 2026):**
   - اختيار الشعبة ثم السنة للوصول المباشر لموضوع الامتحان والتصحيح النموذجي وسلم التنقيط.

3. 🧮 **حاسبة معدل البكالوريا التفاعلية (BAC Calculator):**
   - واجهة تفاعلية لتعديل علامات المواد وحساب المعدل التقديري بالمعاملات الرسمية.
   - خيار تفعيل/تعطيل التربية البدنية والأمازيغية.
   - كشف نقاط تقديري مع التقدير الرسمي (ممتاز، جيد جداً...) واقتراح التخصصات الجامعية المتاحة.

4. 🎯 **بنك الأسئلة والكويزات التفاعلية (QCM Quiz):**
   - اختبارات سريعة من 4 خيارات مع تصحيح فوري وعرض الشرح والتعليل النموذجي المعتمد في الوزارة.

5. ⏳ **العداد التنازلي للبكالوريا (Countdown):**
   - حساب الوقت المتبقي باليوم والساعة والدقيقة والثانية حتى موعد بكالوريا جوان 2026 مع بطاقات تحفيز يومية.

6. 📅 **مخطط المراجعة الأسبوعي (Weekly Planner):**
   - نظام الأهداف الذكي لكل شعبة مقسم إلى فئتين: المتمدرسين والأحرار (Candidats Libres).

7. 🎥 **دليل أساتذة وقنوات اليوتيوب:**
   - أفضل الأساتذة المعتمدين في الجزائر لكل مادة مع الروابط وقوائم التشغيل.

8. 💡 **نصائح ومنهجيات التفوق:**
   - منهجية التعامل مع ورقة الإجابة، تقنية كراس الأخطاء، تسيير الوقت، ومنهجية الفلسفة والعلوم.

9. 🔍 **محرك البحث السريع:**
   - البحث الفوري في جميع الدروس والملفات والأساتذة والأرشيف عبر إرسال الأمر `/search` أو كتابة الكلمة مباشرة في المحادثة.

## 🚀 كيفية تشغيل البوت (Quick Start Guide)

### 1️⃣ الحصول على توكن التيليجرام (Telegram Bot Token):
1. افتح تطبيق تيليجرام وابحث عن المعرف الرسمي: **[@BotFather](https://t.me/BotFather)**.
2. أرسل الأمر `/newbot` واتبع التعليمات لاختيار اسم البوت ومعرفه (يجب أن ينتهي بـ `bot`، مثلاً: `Naja7iBacDZ_bot`).
3. بعد الانتهاء، سيعطيك BotFather الـ **HTTP API Token** (مثال: `123456789:ABCdefGHIjklMNOpqrSTUvwxYZ`).

### 2️⃣ ضبط التوكن في المشروع:
قم بإنشاء ملف `.env` في المجلد الرئيسي `naja7i/` أو داخل مجلد `bot/` وضع فيه التوكن:
```env
BOT_TOKEN="123456789:ABCdefGHIjklMNOpqrSTUvwxYZ"
```

### 3️⃣ تشغيل البوت:
من داخل مجلد `naja7i/` نفذ الأمر:
```bash
npm run bot
```

ستظهر لك رسالة التأكيد:
```
🎉 البوت يعمل بنجاح تحت اسم: @YourBotUsername
🤖 جاهز لاستقبال رسائل تلاميذ البكالوريا في الجزائر 🇩🇿
```
