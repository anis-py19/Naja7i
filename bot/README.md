# 🤖 بوت تيليجرام منصة نجاحي (Naja7i Telegram Bot 🇩🇿)

بوت تيليجرام تفاعلي فائق السرعة مبني باستخدام **Node.js** و **grammY**، يوفر لطلاب شهادة البكالوريا في الجزائر (جميع الشعب الست) وصولاً فورياً لكافة خدمات ومنتجات منصة نجاحي.

---

## 🌟 ميزات البوت الأساسية (Features)

1. 📚 **المكتبة والملخصات المدرسية:**
   - تصفح أكثر من 330 ملف ملخص وسلسلة تمارين ومذكرات وزارية.
   - روابط قراءة ومعاينة مباشرة وتحميل سحابي فوري عبر Google Drive.

2. 🏛️ **أرشيف البكالوريا الكامل (2008 - 2026):**
   - استعراض جميع دورات البكالوريا السابقة مع المواضيع الرسمية والحلول وسلم التنقيط المعتمد.

3. ⏱️ **بنك الكويزات والاختبارات التفاعلية (Quiz Engine):**
   - أسئلة QCM تفاعلية مع خيارات وأزرار فورية.
   - تصحيح لحظي مع إظهار **الشرح والتعليل النموذجي الوزاري** المعتمد.

4. 🧮 **حاسبة معدل البكالوريا والمعاملات:**
   - عرض المعاملات الرسمية لجميع الشعب وحساب المعدل والتقديرات الرسمية.

5. 🎥 **دليل قنوات وأساتذة اليوتيوب:**
   - قائمة منسقة لأفضل الأساتذة الجزائريين مع المنهجية وقوائم التشغيل وروابط القنوات.

6. 📅 **مخطط المراجعة والعد التنازلي:**
   - جداول أهداف المراجعة الأسبوعية للأحرار والمتمدرسين.
   - عداد تنازلي دقيق حتى انطلاق بكالوريا 2026 مع رسائل تحفيزية.

7. 🔍 **البحث الفوري والمدمج (Inline Search Mode):**
   - دعم البحث المباشر في أي محادثة عبر `@YourBotName كلمة_البحث` لمشاركة الملفات مع الزملاء.
   - دعم فتح منصة نجاحي كاملة كـ **Telegram Mini App**.

## 🚀 كيفية الإعداد والتشغيل (Quick Start)

### 1️⃣ إنشاء البوت والحصول على التوكن (BotFather)
1. افتح تطبيق تيليجرام وابحث عن [@BotFather](https://t.me/BotFather).
2. أرسل الأمر `/newbot`.
3. اختر اسماً للبوت (مثلاً: `نجاحي — رفيق البكالوريا`).
4. اختر معرّفاً للبوت ينتهي بـ `bot` (مثلاً: `Naja7iBacBot`).
5. انسخ التوكن (HTTP API Token) المعطى لك.
6. *(اختياري للـ Inline Mode)*: أرسل `/setinline` لـ BotFather واختر بوتك لتمكين ميزة البحث داخل المحادثات.

### 2️⃣ ضبط المتغيرات البيئية (.env)
قم بإنشاء ملف `.env` داخل مجلد المشروع (أو مجلد `bot/`):
```env
BOT_TOKEN=1234567890:ABCdefGhIJKlmNoPQRsTUVwxyZ
WEB_APP_URL=https://naja7i.vercel.app
```

### 3️⃣ تشغيل البوت محلياً (Run Locally)
من داخل مجلد المشروع الرئيسي:
```bash
# تشغيل البوت
npm run bot

# أو تشغيل البوت في وضع التطوير (Auto-reload)
npm run bot:dev
```

## 🌐 التشغيل السحابي 24/7 بدون الحاجة لتشغيل جهازك (24/7 Cloud Hosting)

تم إعداد البوت ليعمل بنظام **Vercel Serverless Webhook** مجاناً ومدى الحياة بدون أن تحتاج لفتح حاسوبك أو تشغيل `npm run bot`!

### ⚡ الخطوات البسيطة للتفعيل:
1. **في لوحة تحكم Vercel:**
   - ادخل لمشروعك في Vercel -> إعدادات المشروع (**Settings**) -> **Environment Variables**.
   - أضف المتغير: `BOT_TOKEN` وضَع فيه توكن البوت الخاص بك.
2. **رفع التحديثات (Deploy):**
   - قم بعمل Deploy للمشروع على Vercel لرفع ملف `api/webhook.js`.
3. **تفعيل الـ Webhook:**
   - شغّل الأمر:
     ```bash
     npm run bot:set-webhook
     ```
   - سيقوم البوت فوراً بالربط مع `https://naja7i-platform.vercel.app/api/webhook`.

---

## 🛠️ الأوامر المتاحة في المشروع:
- `npm run bot` : تشغيل محلي في بيئة التطوير (Long Polling).
- `npm run bot:set-webhook` : تفعيل الربط السحابي 24/7 مع Vercel.
- `npm run bot:delete-webhook` : إلغاء الـ Webhook في حال أردت العودة للتشغيل المحلي.

## 📋 قائمة أوامر البوت (Bot Commands)
- `/start` - القائمة الرئيسية والترحيب
- `/library` - تصفح مكتبة الملفات والملخصات
- `/bac` - أرشيف مواضيع وحلول البكالوريا (2008-2026)
- `/quiz` - بدء كويز تفاعلي سريع
- `/calc` - حاسبة معدل البكالوريا والمعاملات
- `/teachers` - دليل قنوات وأساتذة اليوتيوب
- `/planner` - مخطط المراجعة الأسبوعي
- `/countdown` - العداد التنازلي لبكالوريا 2026
- `/search <query>` - بحث فوري في قاعدة البيانات
- `/help` - دليل المساعدة والأوامر
